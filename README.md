# FUVEST 2027 — Sistema de estudo

## Como usar

1. Abra a pasta da matéria que deseja estudar.
2. Abra `conteudo.md` — é o checklist de tópicos.
3. Escolha um item e estude.
4. Abra `materials.md` — fontes e recursos recomendados.
5. Anote resumos em `resumo.txt`.
6. Marque o item como concluído em `conteudo.md`.

## Estrutura

```
01-LINGUAGENS/       → português, literatura, inglês, redação
02-MATEMATICA/       → álgebra, funções, geometria, estatística
03-CIENCIAS-NATUREZA/ → biologia, física, química
04-CIENCIAS-HUMANAS/  → história, geografia, filosofia, sociologia
```

Cada matéria tem:
- `conteudo.md` — tópicos com checklist
- `materials.md` — fontes e recursos
- `resumo.txt` — suas anotações
